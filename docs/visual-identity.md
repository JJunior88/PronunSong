# Identidade visual — PronunSong

O símbolo combina um balão de fala, que representa pronúncia e comunicação, com uma nota musical. A marca usa formas simples, sem texto dentro do ícone, para manter a leitura em telas pequenas.

- Verde floresta: `#243D32` — fundo do ícone.
- Lima suave: `#D3E7A6` — símbolo e destaques.
- Marfim quente: `#F8F7F2` — fundo da interface.
- Assinatura: **Encontre sua voz.**

O arquivo vetorial mestre para web é `src/icon.svg`. No Android, o desenho está em `ic_launcher_foreground.xml`, com fundo separado para as máscaras adaptáveis do launcher e suporte a ícones temáticos. Não distorça o símbolo nem acrescente detalhes pequenos. A apresentação conceitual está em `visual-identity.png`; os vetores são os arquivos de produção.
