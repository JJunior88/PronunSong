# Identidade visual — PronunSong

Nome mantido: **PronunSong**. A direção escolhida pelo usuário usa um anel circular, nota musical e barras de voz, em gradiente ciano–violeta–magenta sobre fundo noturno. Substitui a identidade verde anterior.

- Fundo noturno: `#101024`.
- Ciano: `#00C8FF`.
- Violeta intermediário: `#925CFF`.
- Magenta: `#ED00E8`.
- Texto claro: `#F6F3FF`.
- Slogan: **Cante em inglês. Pronuncie com confiança.**

O vetor web está em `src/icon.svg`. Os vetores Android ficam em `android/app/src/main/res/drawable/`, incluindo versão monocromática para ícones temáticos do Android. O launcher aplica sua própria máscara circular ou arredondada. Não distorça o símbolo nem insira o nome dentro do ícone. A apresentação conceitual está em `visual-identity.png`; os vetores são os arquivos de produção.
